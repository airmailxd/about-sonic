Suggested path

  1. Read the SONiC Guide's ELI5 and overview until you can sketch the architecture from memory.
  2. For each chapter, review the Key Concepts first. Try to make the SONiC connection yourself before you open the dropdown.
  3. Then answer that chapter's Q&A aloud before you open each answer.
  4. Learn the delivery framework, then practice the question breakdowns against the clock: write the requirements, entities and API yourself before you open the answers.
  5. Finish with SONiC vs Ceph to practice reasoning about trade-offs across two real systems.
